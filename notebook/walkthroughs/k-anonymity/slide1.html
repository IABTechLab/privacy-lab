Effect of Parameter on Results: Walkthrough¶

Set the slider to k = 1 and note that even with k-anonymity, each user is a member of their own group of 1 and so each row has the exact attribute value in each column. Even if a row's particular combination of attribute values never appears in another row (which means an individual user can be identified uniquely using that combination), that combination of values is reproduced verbatim in the output.
