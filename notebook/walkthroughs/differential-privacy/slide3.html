Effect of Privacy Loss Parameter on Results: Walkthrough¶

Finally, increase the maximum number of queries permitted to 10 and observe that the differentially private results can appear even more noisy. This occurs because each query leaks some amount of the information about the true data, so allowing more queries while maintaining the same amount of privacy loss necessarily degrades the accuracy of the result for each query.
