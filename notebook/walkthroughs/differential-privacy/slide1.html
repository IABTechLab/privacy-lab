Effect of Privacy Loss Parameter on Results: Walkthrough¶

Set the epsilon value to 5, which represents a relatively high privacy loss. This implies fairly accurate results, and this can be seen by comparing a differentially private result (represented by the orange vertical bars) to the true result (represented by the blue vertical bars). In both cases, the counts for each campaign are quite close.
